# 🚀 Personal Portfolio - Mohanad Mohamed

A professional, responsive portfolio website built to showcase my work, skills, and passion for Front-End development.

## 🛠️ Tech Stack

- **Languages:** HTML5, CSS3, JavaScript (ES6+)
- **Frameworks:** React.js, Bootstrap 5
- **Icons & Fonts:** FontAwesome, Google Fonts (Inter)
- **Deployment:** GitHub Pages

## ✨ Key Features

- **Modern Dark UI:** Deep navy theme with high-contrast typography.
- **Responsive Design:** Optimized for Mobile, Tablet, and Desktop.
- **Intersection Observer:** Navigation links that update automatically as you scroll.
- **Functional Contact Form:** Powered by Formspree API.
